# Changelog

All notable changes to this project are documented in this file.

## [0.1.0] - 2026-03-19

### Added

- Production package structure under `src/circuit_packing`.
- Simulator-first CLI with `run`, `benchmark`, and `validate` commands.
- End-to-end pipeline orchestration with output artifact generation.
- Unit and integration tests for partitioning, demux, benchmark, and simulator pipeline paths.
- Tooling and CI (`ruff`, `mypy`, `pytest`, GitHub Actions workflows).
- Documentation set for architecture, reproducibility, and scientific validity considerations.
